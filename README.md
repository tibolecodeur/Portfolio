# Portfolio — Thibault Brebion

Portfolio statique (HTML / CSS / JavaScript) : parcours, compétences, certifications, projets BTS SIO SLAM, stages, veille technologique et tableau de synthèse.

## Stack
- HTML5, CSS3, JavaScript vanilla
- [GSAP + ScrollTrigger + Draggable](https://gsap.com/) pour les animations
- [Lenis](https://lenis.darkroom.engineering/) pour le scroll fluide

## Lancer en local
Aucun build : ouvrir `index.html` dans un navigateur, ou lancer un serveur statique :

```bash
npx serve .
```

## Structure
```
index.html
assets/
  css/styles.css
  js/data.js        # contenu : skills, projets, stages
  js/script.js      # animations, panneaux, filtres, formulaire
  images/           # photo + vignettes projets (WebP)
  files/            # tableau de synthèse (.xlsx)
```
